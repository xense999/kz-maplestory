# 浮動面板工廠 — 模組規範

> 本模組契約的唯一 owner。建檔後記得回寫 `docs/規範.md` 歸屬總表的規範檔欄。

## 公開介面

- `createFloatPanel<T, I>(label)`：造一個面板的遙控器
- 主視窗側：`toggle`、`setOpacity`、`push`、`pushOpacity`、`fitRows`、`onHello`、`onInput`
- 面板側：`onData`、`onOpacity`、`sayHello`、`sendInput`
- 各面板的實例與它們的快照型別（輪燒、角色進度、幣值換算）

## 單一來源

- 面板之間的事件名。一律由 label 衍生（`<label>:data` 等），不在別處手寫字串
- 面板的透明度設定

## 不變量

- 每個面板都在 `tauri.conf.json` 宣告、開機建好但隱藏；這裡只切換顯示
- 關閉一律用 hide
- 主視窗是唯一的資料來源。可以打字的面板把修改送回主視窗（`sendInput`），
  由主視窗改狀態再廣播回來；面板不自己保存狀態
- 面板載入時喊 hello，主視窗收到一定要回，即使內容跟上次送的一樣

## 禁止

- 不在執行期 `new WebviewWindow` —— 正面做法：寫進 `tauri.conf.json` 的 windows；
  執行期建出來的子視窗有過空白不 render 的前例
- 不用 `close()` 關面板 —— 正面做法：`hide()`。關掉的視窗叫不回來，就沒得再開了
- 面板不把自己的狀態存進儲存區 —— 正面做法：狀態放主視窗那一份
