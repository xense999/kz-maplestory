# 幣值換算狀態 — 模組規範

> 本模組契約的唯一 owner。

## 公開介面

- `rateText`、`ntdText`、`mesoText`：買幣三個欄位的文字
- `sellMesoText`、`sellNtdText`、`sellAnchor`、`setSellMeso`、`setSellNtd`：賣幣那張卡
- `vip`：VIP 開關
- `mode`：浮動面板現在在算買還是賣
- `rate`、`deal`：算出來的匯率數值與這一筆交易的四個數字
- `setRate(text)`、`setNtd(text)`、`setMeso(text)`：使用者動了哪一欄
- `init()`：由 App 啟動時呼叫一次，接上浮動面板

## 單一來源

- 這一頁所有欄位的值。主頁與浮動面板都讀這一份，面板不另存一份

## 不變量

- 欄位值一律是字串：空字串與 `"0"` 是不同的事（沒填 vs 填了零）
- 匯率欄的單位是 W／台幣，楓幣欄填的是**楓幣本身**（不是 W）
- 同一時間只有一個金額欄位是「來源」，另一個由它算出來
- 改幣值不換來源欄——畫面上「算出來的」那個標記必須一直是真的
- 匯率、VIP 與面板模式存進瀏覽器儲存區；金額一律不存——每筆交易都不一樣

## 禁止

- 兩個金額欄位不互相反推 —— 正面做法：記住使用者最後動的是哪一欄，只算另一欄，
  否則往返的浮點誤差會讓數字自己抖動
