# 久世管理器

楓之谷的桌面小工具。三頁各管一件事，數字都能丟到浮動視窗上，回到遊戲裡照樣看得到。

Windows 桌面程式（Tauri 2 + Vue 3 + TypeScript + Rust）。

## 它在做什麼

| 頁 | 在算什麼 |
| --- | --- |
| 經驗追蹤 | 一排角色卡片，比誰練得快 |
| 計時器 | 出租、加持、輪迴、燃燒四種倒數 |
| 幣值換算 | 楓幣現金交易的手續費換算 |

### 經驗追蹤

加幾張角色卡片、填上名字，等級與經驗進度就自己抓回來，之後定時更新。
「今天練了」是今天 00:00 到現在的成長量（一級算 100%），拿來跟別人對照進度。
卡片可以拖曳排順序，每張右邊的開關決定它要不要出現在浮動視窗上。

資料來自官方 API，要先在設定頁貼上你自己的遊戲 API 金鑰——怎麼申請，設定頁裡有一步一步的說明。
請求走後端（`src-tauri/src/maple.rs`）而不是 webview：官方 API 不給跨來源標頭，前端直接打會被擋。

### 計時器

| 計時器 | 時長 | 怎麼起算 |
| --- | --- | --- |
| 出租計時 | 30 分 / 1 小時 / 1 小時 30 分 / 2 小時 / 自訂（15 分為單位） | 下面任一張技能卡第一次觸發時跟著起算，之後一路跑到結束 |
| 加持計時器 | 預設 30 分 | 每按一次按鍵就從頭重算。可以自己新增、改名、刪除，要幾張開幾張 |
| 輪迴計時器 | 9 分 50 秒 | 每按一次按鍵就從頭重算 |
| 燃燒計時器 | 14 分 50 秒 | 每按一次按鍵就從頭重算 |

時間到會一直響到有人處理，卡片同時轉紅。按下「停止提醒」會收鈴並把到期的那一輪歸零——
出租因此可以直接跟著下一次技能觸發開新的一輪。倒數存的是「到期時刻」而不是「還剩幾秒」，
所以電腦睡醒、視窗最小化都不會算錯。

#### 按鍵不會被搶走

每張技能卡片可以綁一顆按鍵（點鍵帽錄一次，按右鍵清除，旁邊的開關打開才生效）。

這裡用的是**只監聽、不攔截**的鍵盤 hook（`WH_KEYBOARD_LL`＋`CallNextHookEx` 原樣放行），
不是系統全域快捷鍵。差別在於：全域快捷鍵一註冊，那顆鍵就從遊戲手上被拿走；
這裡則是你按下去技能照樣放得出來，計時只是順便起算。所以按鍵可以直接綁在放技能的那顆鍵上。

同一顆鍵綁在兩張卡上時，兩張都會反應。

### 幣值換算

買幣填「需求楓幣」或「約當現金」，另一邊自己算出來，手續費扣完的「實收楓幣」一併列出；
賣幣填「持有楓幣」或「約當現金」，算出可販售楓幣與可獲得現金。
打進去的數字旁邊會直接標出談價用的級距，不必自己數零。

「當前幣值」與「商城幣值」分開填——**商城那個是倒數關係，不是換個單位而已**。

## 浮動視窗

三頁各有一顆「浮動視窗」按鈕，按一下開、再按一下關。永遠置頂、整塊可拖、固定深色
（它蓋在遊戲畫面上，淺色會變成一塊刺眼的白）。
滑鼠停在那顆按鈕上會出現透明度拉桿（0~100%）與「文字陰影」開關——底色調得再淡，數字仍是實心的。

每個面板都是另一個 webview，記憶體不共用，資料靠事件同步。面板在 `tauri.conf.json` 宣告好、
開機就建起來但 `visible: false`，開關只切換顯示。
**不在執行期 `new WebviewWindow`**——那樣建出來的子視窗有過空白不 render 的前例；
**關閉一律 `hide` 不用 `close`**——close 掉的視窗叫不回來。

## 安裝

到 [Releases](https://github.com/xense999/kz-maplestory/releases) 下載 `kz-maplestory_x.y.z_x64-setup.exe`。

裝好之後，設定頁（左上角齒輪）→ 右下角的 `i` → 「檢查更新」可以直接更新到新版，不必再手動下載。

## 開發

```powershell
npm install
npm run tauri dev     # dev server 固定 1440 埠
npm run build         # vue-tsc 型別檢查 + 前端打包
npm test              # vitest（幣值換算的算術）
```

## 發版

推一個 `v` 開頭的 tag，GitHub Actions 會自動 build 並建立 Release：

```powershell
# 1. 版號要對齊：package.json / package-lock.json / src-tauri/Cargo.toml / Cargo.lock / tauri.conf.json
# 2. 寫 release-notes/v<版號>.md 並先 commit（沒寫的話 Release 內文退回 _default.md）
git tag v1.0.0
git push origin v1.0.0
```

Release 會附兩個檔案：安裝檔（給人下載）與裸 `kz-maplestory.exe`（給程式內更新就地置換）。
**因此任何執行期需要的檔案都必須編進 exe，不能只放進 `bundle.resources`** ——
那種檔案到不了用程式內更新的人手上。

## 結構

每個模組的 owner 程式與契約文件在 [`docs/規範.md`](docs/規範.md)，那張表是唯一來源，這裡不重抄。
起手看三支就夠：

| 路徑 | 作用 |
| --- | --- |
| `src/nav.ts` | 導覽列＝這張表。加功能頁只要寫一支 `views/*.vue` 再加一列 |
| `src/styles.css` | 全站唯一的樣式來源（token 在 §1） |
| `src/float.ts` | 浮動面板工廠：開關、透明度與跨視窗同步都在這裡 |
