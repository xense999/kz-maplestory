# 久世管理器

![Tauri](https://img.shields.io/badge/Tauri-2-blue) ![Vue](https://img.shields.io/badge/Vue-3-42b883) ![Rust](https://img.shields.io/badge/Rust-orange)

楓之谷的第三方桌面輔助工具，把練功、輪燒與交易要看的數字收在同一個視窗裡。

## 功能

- 角色經驗追蹤（`一排卡片並列，比誰練得快`）
- 今日成長量（`今天 00:00 到現在練了多少，一級算 100%`）
- 輪迴／燃燒計時（`9 分 50 秒、14 分 50 秒，按一次重算`）
- 加持計時器（`可自行新增、改名、刪除，要幾張開幾張`）
- 出租計時（`技能第一次觸發時跟著起算，中途再按不會洗掉客戶的時間`）
- 只聽不攔的按鍵綁定（`按鍵不會被搶走，技能照樣放得出來`）
- 到期通報（`響到你處理為止，卡片同時轉紅，音量可調`）
- 楓幣買賣換算（`手續費扣完的實收與可獲得現金一併算出`）
- 商城幣值換算（`與當前幣值分開填，兩者是倒數關係`）
- 浮動視窗（`三頁各一個，永遠置頂、可拖、透明度可調`）
- 亮色 / 暗色主題（`設定後自動記住`）
- 開機時啟動（`登入 Windows 後自動開啟`）
- 自動檢查本程式更新，可直接下載安裝

## 系統需求

- Windows 10 / 11
- 遊戲 API 金鑰（`經驗追蹤才需要，程式內有申請教學`）

## 下載安裝

從 [GitHub Releases](../../releases) 下載最新版本的 `.exe` 安裝檔。

## 使用方式

:small_orange_diamond:**經驗追蹤** `看誰練得比較快`

1. 設定頁（左上角齒輪）貼上你自己的遊戲 API 金鑰，旁邊的 `i` 有一步一步的申請教學
2. 回到經驗追蹤頁新增卡片、填入角色名稱，等級與經驗進度會自己抓回來並定時更新
3. 卡片可以拖曳排順序；右邊的開關決定它要不要出現在浮動視窗上

:small_orange_diamond:**輪燒計時** `綁在你放技能的那顆鍵上`

1. 點技能卡片上的鍵帽錄一顆鍵（`按右鍵清除`），再把旁邊的開關打開
2. 之後每按一次那顆鍵，倒數就從頭重算——技能照常放得出來，計時只是順便起算
3. 時間到會一直響到有人處理，按「停止提醒」收鈴並把到期的那一輪歸零

:small_orange_diamond:**出租計時** `按時段賣的那種`

1. 先選時長：30 分、1 小時、1 小時 30 分、2 小時，或直接點數字自訂（`5 分鐘為單位，最短 5 分`）
2. 輪迴或燃燒任何一張第一次觸發時，出租就跟著開始，然後一路跑到結束
3. 要重來請按卡片上的「重新計時」或「歸零」

:small_orange_diamond:**幣值換算** `談價前先算清楚`

1. 「買幣」填需求楓幣或約當現金，另一邊自己算出來，手續費扣完的實收楓幣一併列出
2. 「賣幣」填持有楓幣或約當現金，算出可販售楓幣與可獲得現金
3. 打進去的數字旁邊會直接標出談價用的級距，不必自己數零

:small_orange_diamond:**浮動視窗** `回到遊戲裡也看得到`

1. 三頁各有一顆「浮動視窗」按鈕，按一下開、再按一下關（`永遠置頂、整塊可以拖`）
2. 滑鼠停在那顆按鈕上會浮出透明度拉桿與「文字陰影」開關——底色調得再淡，數字仍是實心的
3. 幣值換算的面板可以直接在上面打字，改的是同一份資料，切回主視窗兩邊一致

## 開發

```powershell
npm install
npm run tauri dev     # dev server 固定 1440 埠
npm run build         # vue-tsc 型別檢查 + 前端打包
npm test              # vitest（幣值換算的算術）
```

每個模組的 owner 程式與契約文件在 [`docs/規範.md`](docs/規範.md)，那張表是唯一來源。
起手看三支就夠：`src/nav.ts`（導覽列＝那張表）、`src/styles.css`（全站唯一的樣式來源）、
`src/float.ts`（浮動面板工廠）。

浮動面板有兩條鐵則：**不在執行期 `new WebviewWindow`**（那樣建出來的子視窗有過空白不 render 的
前例，一律在 `tauri.conf.json` 宣告）、**關閉一律 `hide` 不用 `close`**（close 掉的視窗叫不回來）。

## 發版

推一個 `v` 開頭的 tag，GitHub Actions 會自動 build 並建立 Release：

```powershell
# 1. 版號要對齊：package.json / package-lock.json / src-tauri/Cargo.toml / Cargo.lock / tauri.conf.json
# 2. 寫 release-notes/v<版號>.md 並先 commit（沒寫的話 Release 內文退回 _default.md）
git tag v1.0.0
git push origin v1.0.0
```

Release 會附兩個檔案：安裝檔（給人下載）與裸 `kz-maplestory.exe`（給程式內更新就地置換）。
**因此任何執行期需要的檔案都必須編進 exe，不能只放進 `bundle.resources`** ——
那種檔案到不了用程式內更新的人手上。
